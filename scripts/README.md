# Scripts — NexoCommerce

Scripts auxiliares para automatizar tareas del proyecto.

## Posibles scripts

```text
scripts/
├── instalar/
├── desarrollo/
├── base-datos/
├── docker/
├── pruebas/
└── despliegue/
```

## Ejemplos

* Inicialización del proyecto.
* Migraciones.
* Seeders.
* Levantar contenedores.
* Detener contenedores.
* Ejecutar pruebas.
* Backup.
* Restauración.

## Regla

Los scripts deben ser seguros, documentados y no deben contener credenciales.
